# Whiteboard pane

This directory is the complete WPS7 whiteboard plugin. Copy the whole
`whiteboard/` directory into another compatible installation's
`plugin-panes/` directory and refresh WPS7 to load it.

The pane runs as a trusted host plugin because Excalidraw needs browser APIs
that are unavailable inside the sandbox used by ordinary HTML plugins. Review
the JavaScript before installing a copy from another source.
